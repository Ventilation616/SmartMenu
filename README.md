# SmartMenu

智能菜单，根据你的现实食材用量动态调整所有配方比例。

## 仓库结构

- `docs/`：需求、技术栈与任务拆分文档
- `smart_menu_app/`：Flutter 应用工程

## 当前进度

- 需求文档已整理完成
- 技术栈规范已确定
- M1 工程骨架已落地
- M2 数据模型与持久化已落地
- M3 核心业务能力已落地

当前仓库已完成：

- Flutter 工程初始化与基础依赖配置
- 分层目录结构、应用入口与路由骨架
- `freezed` 领域模型与值对象
- Drift 本地数据库、三张核心表与 DAO
- 配方仓储实现与数据映射
- Decimal 解析、格式化与精度取整工具
- 配方保存校验与业务异常
- 新建配方、编辑配方保存、列表查询、详情查询、搜索、删除等核心用例
- 动态比例计算规则与 Provider 暴露

当前仓库尚未完成：

- M4 页面业务联动与完整表单交互
- M5 测试补齐与联调收尾
