## **四、编码规范**

### **4.1 Dart 编码规范**

- 遵循 [Effective Dart](https://dart.dev/effective-dart) 官方规范
- 使用 `flutter_lints` 或 `very_good_analysis` 作为 Lint 规则集
- 命名约定：
  - 类名：`UpperCamelCase`
  - 变量/方法：`lowerCamelCase`
  - 常量：`lowerCamelCase` 或 `SCREAMING_SNAKE_CASE`
  - 文件：`snake_case.dart`

### **4.2 模型规范**

所有领域模型必须：

- 使用 `freezed` 生成不可变类
- 实现 `copyWith` 深拷贝方法
- 实现 `toJson` / `fromJson` 序列化
- 金额/用量字段统一使用 `Decimal` 类型

### **4.3 状态管理规范**

- 全局状态使用 `Riverpod` Provider
- 页面级状态使用 `StateNotifierProvider` 或 `FutureProvider`
- 禁止在 Widget 中直接持有可变状态
- 所有异步操作必须处理 Loading / Error / Data 三种状态

### **4.4 数据库规范**

- 所有写操作必须在 `transaction` 中执行
- 使用 Drift 的类型安全查询，避免拼接 SQL 字符串
- 关联数据（食材、步骤）使用级联删除

text

```
向下取整：floor(amount / precision) × precision
```

## **十、技术债务与扩展预留**

### **10.1 预留扩展点**

- 图片附件：预留 `asset` 字段，暂不实现
- 数据导出/导入：预留 JSON 序列化接口
- 多语言：使用 `intl` 和 ARB 文件
- 暗黑模式：使用 Flutter Theme 机制

### **10.2 不引入的技术（V1.0）**

- 网络请求库（dio/http）—— 无网络需求
- 响应式框架（RxDart）—— 不需要
- 数据库加密（sqflite\_sqlcipher）—— V1.0 不需要
- 图片处理（image\_picker）—— 预留但暂不引入依赖
